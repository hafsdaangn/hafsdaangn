# 합스당근 MVP 디자인 초안

2026-09-24. 구현 전 검토용이며 디자인 확정본이 아니다.

## 방향

학교 계정 보유자가 물건과 상대방을 빠르게 찾는 모바일 중심 웹 서비스. 사진, 제목, 가격 또는 분실 장소가 먼저 읽히는 담백한 목록형 UI를 사용한다. 판매·나눔은 장터에 통합하고 분실물은 별도 탭으로 제공한다.

흰 배경, 진한 글자, 얇은 구분선, 주황색 주요 행동 버튼을 사용한다. 나눔·습득 표시는 연한 초록색과 텍스트를 함께 사용한다. 관심·차단·신고·운영자·결제·평점 기능은 목업과 MVP에서 제외한다.

## 내비게이션과 반응형

- 모바일의 주요 화면 하단: 장터 / 분실물 / 채팅 / 내 정보.
- 상세 화면: 뒤로 가기와 하단 주요 행동 버튼. 하단 탭은 숨긴다.
- 채팅방: 뒤로 가기와 메시지 입력창. 하단 탭은 숨긴다.
- 글쓰기: 한 화면의 세로 폼. 등록 버튼은 입력 및 업로드 상태를 반영한다.
- 모바일 장터는 사진 왼쪽·텍스트 오른쪽 목록. 큰 홍보 배너는 두지 않는다.
- PC는 최대 약 1120px 콘텐츠 영역, 상단 내비게이션. 장터는 2열 상품 목록을 검토한다.
- PC 상품 상세는 사진과 정보의 2열, 채팅은 대화 목록과 대화 본문의 2열.
- 실제 구현 시 320/375/414/768px 및 넓은 PC 화면, 키보드 열린 채팅, safe-area를 검증한다. 이미지 목업은 반응형 검증 결과가 아니다.

## 상태 설계

- 판매 중/예약 중/완료는 색상뿐 아니라 텍스트로 표시한다.
- 작성자에게는 자신의 글에서 수정·삭제·상태 변경을 제공하고 자신의 글에 채팅하기는 표시하지 않는다.
- 나눔 선택 시 가격 입력을 숨기고 나눔으로 표시한다.
- 완료된 글은 신규 문의를 막고 기존 대화로 돌아갈 수 있게 한다.
- 빈 목록은 짧은 안내와 글쓰기, 검색 결과 없음은 필터 해제를 제공한다.
- 로딩은 목록 뼈대, 실패는 실패 원인과 재시도 행동을 표시한다.
- 채팅은 전송 중·실패·재시도·읽음을 구분한다.
- 분실물은 가격을 표시하지 않고 장소·시점·보관 방식에 우선순위를 둔다.
- 색 대비, 키보드 포커스, 스크린리더 이름, 버튼 누르기 영역은 실제 구현에서 검증한다.

## 목업

장터 / 상품 상세 / 채팅 / 분실물을 한 보드로 생성한다. 상품·닉네임·가격·장소·대화는 모두 디자인 검토용 예시이며 실제 학교 시설 확인이나 사용자 데이터가 아니다. ImageGen 내장 도구를 사용한다. 생성 이미지의 세부 한글과 간격은 실제 컴포넌트 구현 시 정밀하게 맞춘다.

Hallmark 적용 범위: 화면 계층, 절제된 색상, 일관된 간격, 실제 과업 중심 구성. 이번 산출물은 정적 이미지 초안이며 동작·반응형·접근성 테스트 통과를 의미하지 않는다.
