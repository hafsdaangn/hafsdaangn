# Google 계정 이름 사용

닉네임 입력·수정과 최초 닉네임 설정 화면을 제거했습니다. 게시글 작성자, 채팅 상대, 내 정보, 채팅 알림은 `profiles.display_name`을 표시합니다.

이름은 로그인에 연결된 Google identity의 `name`을 사용하고, 이전 형식의 데이터는 `full_name`을 사용합니다. 별도의 닉네임 길이 제한이나 실명 형식 검사 없이 계정 이름을 저장합니다. 이름이 없는 예외 상황에서는 임의 닉네임을 만들지 않으며 거래·채팅을 막지 않습니다.

## DB 적용

새 마이그레이션: `supabase/migrations/20261024133234_google_account_names.sql`

- 기존 `nickname` 컬럼을 `display_name`으로 전환하고 닉네임 길이 제약을 제거합니다.
- 기존 활성 회원의 이름을 Google identity에서 일괄 가져옵니다.
- Google identity 생성·갱신 시 이름을 동기화합니다. Google에서 이름을 바꾼 경우 다음 Google 로그인에서 갱신됩니다.
- 사용자 정의 이름 저장 RPC와 닉네임 설정 필수 조건을 제거합니다.
- 회원 권한·학교 이메일 검증과 기존 탈퇴 계정 익명화는 유지합니다.

이 소스 변경과 DB 마이그레이션은 함께 배포해야 합니다. 이전 웹 앱은 `nickname`을 조회하므로 운영 적용 시 유지보수 시간을 잡고 새 마이그레이션 적용과 새 앱 배포를 연속으로 진행합니다. 과거 마이그레이션 파일은 수정하지 않습니다.

2026-10-24 사용자가 운영 DB 마이그레이션을 적용했으며, `display_name` 컬럼 조회가 정상 응답하는 것을 확인했습니다. 웹 앱은 GitHub `main`을 통해 Vercel에 배포합니다. 로컬 PGlite 테스트에서 새 가입, 기존 회원 전환, 한 글자·긴 이름, Google 이름 갱신, 임의 변경 차단을 검증합니다.
