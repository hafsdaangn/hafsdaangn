로고 사용 가이드

v1.0 · 2026.11.06

01 · 기본 조합과 여백

가로형 컬러 로고를 기본으로 사용합니다. 좁은 공간에는 심볼 단독, 정사각형 홍보물에는 세로형을 사용합니다.

로고 바깥에는 심볼 높이의 10% 이상 비워 둡니다. 파일에 포함된 여백이 부족하면 배치할 때 추가합니다.

늘이기·압축·기울이기·글꼴 교체·HAFS 분리·임의 재배치·그림자 추가를 피합니다.

02 · 최소 크기와 배경

가로형: 화면 160px / 인쇄 30mm 이상 권장.
심볼: 화면 24px / 인쇄 8mm 이상 권장.
16px는 전용 favicon 파일만 사용합니다.

컬러는 흰색·밝은 중성 배경에 사용합니다. 짙은 배경에는 white 버전, 단색 인쇄에는 black 또는 blue 버전을 선택합니다.

03 · 지정 색상

HAFS Blue · #0054B8

RGB 0 / 84 / 184
CMYK 근사 100 / 54 / 0 / 28

Daangn Orange · #FF6800

RGB 255 / 104 / 0
CMYK 근사 0 / 59 / 100 / 0

색상은 마지막 시안의 파랑·주황을 기준으로 단색화했습니다. CMYK는 프로파일 없는 계산 근사값입니다. 인쇄 PDF는 RGB이며 인쇄소의 ICC 변환·실물 교정을 거쳐 사용합니다. Pantone은 지정하지 않았습니다.

05 · 원본과 타이포그래피

사용자가 선택한 마지막 생성 이미지를 기준으로 윤곽을 정리한 벡터입니다. 원본과 미세한 곡선 차이가 있을 수 있습니다. HAFS와 ‘당근’은 이미지에서 추출한 경로로 제공하며 설치용 폰트는 포함하지 않습니다. 원본의 특정 서체명·라이선스는 확인되지 않았습니다.

마스터에는 라이브 글자·임베디드 이미지·필터가 없습니다. 원본 참조는 source/approved-reference.png에 보존했습니다. 상표 유사성·학교 심볼 사용 권한 확인과 인쇄 교정은 별도입니다.
